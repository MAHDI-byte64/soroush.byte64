# استودیو سروش — گالری معماری

سایت استاتیک (HTML/CSS/JS خالص، بدون نیاز به build) با سبک مینیمال و هنری، به شکل یک گالری هنری.

## صفحات
| فایل | محتوا |
|---|---|
| `index.html` | هیرو، دیوار گالری آثار با فیلتر کاربری، بیانیه و آمار |
| `project.html?p=<slug>` | مشخصات پروژه، متن مفهومی، افتخارات، زبانه‌های «عکس‌های اجرا شده / رندرها / نقشه‌ها» با لایت‌باکس، اثر بعدی |
| `about.html` | معرفی استودیو، اصول طراحی، تیم، خدمات، افتخارات |
| `contact.html` | اطلاعات تماس، فرم درخواست همکاری، نقشه |

## ویرایش محتوا
همه چیز در `assets/js/data.js` است:
- `STUDIO` — نام، ایمیل، تلفن، نشانی و شبکه‌های اجتماعی
- `PROJECTS` — هر پروژه با مشخصات و سه فهرست تصویر: `built`، `renders`، `drawings`

برای عکس واقعی، فایل را در `assets/images/<slug>/` بگذارید و مسیرش را در `src` بنویسید.
تا وقتی `src` خالی است، یک پلاک هنری انتزاعی با پالت رنگی همان پروژه (`palette`) نمایش داده می‌شود.

## اجرا
```bash
cd architecture-gallery && python3 -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. برای انتشار، کل پوشه را روی هر هاست استاتیک (مثل GitHub Pages) بگذارید.

فرم تماس بدون سرور، پیام را در برنامه ایمیل کاربر باز می‌کند؛ برای ارسال مستقیم آن را به سرویسی مثل Formspree وصل کنید.
